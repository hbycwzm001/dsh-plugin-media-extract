# 视频解析插件 · 使用手册

> 🗺️ 一页纸版本（网页图谱，可直接发给别人）：[使用图谱.html](使用图谱.html)

> 一句话：粘一条链接 → 20~60 秒 → 拿到**无水印原片 + 文案 + 语音转写**。
> 支持：抖音、小红书、TikTok、YouTube、Facebook、X（推特）、Instagram。

## 二、依赖清单（必须 / 可选，写清楚）

### 2.1 必须

| 依赖 | 说明 | 谁装 |
|---|---|---|
| **DSH Desktop** ≥ 0.2.2-rc.1 | 宿主应用，插件跑在它里面 | 用户装 |
| **本插件** `dsh-plugin-media-extract` | 界面「解析」+ 工具 `media_extract` | 加一次 |
| **解析引擎** `extract.exe`（约 240MB zip） | 真正干活的程序，**首次解析自动下载** | 插件自动装 |

### 2.2 引擎里已经打包了什么（用户不用单独装）

| 组件 | 作用 | 大小 |
|---|---|---|
| Python 运行时（PyInstaller 冻结） | 运行引擎 | 内置 |
| **yt-dlp** + **yt-dlp-ejs** | 海外平台下载、解 YouTube 的 n 挑战 | 内置 |
| **quickjs** | JS 运行时，没装 Node 也能解 YouTube 挑战 | 内置 |
| **ffmpeg** | 合并音视频、HLS 拼接 | 内置 |
| **sherpa-onnx** + **SenseVoice-Small int8 模型** | 语音转文字（中/英/日/韩/粤） | **228MB** |
| requests / urllib3 / curl_cffi | 网络请求 | 内置 |

> 模型文件 `models\sense-voice-onnx\model.int8.onnx`（228.15MB）+ `tokens.txt` 随引擎包一起下发，
> 解压后就在 `~/.dsh/media-extract/extract-tool/models/`。
> **不需要再单独下载模型**，也不需要装 Python、Node、ffmpeg。

### 2.3 可选（不装也能跑，装了成功率更高）

| 可选件 | 什么时候需要 | 不装的后果 |
|---|---|---|
| **ego lite 浏览器**（Citro Labs） | 抖音/小红书图文、需登录才给看的页面 | 抖音/小红书失败率明显变高 |
| **代理出口**（IP+端口+账号密码） | YouTube / TikTok / X / IG / FB | 国内网络下海外平台基本打不开 |
| **各平台登录态**（Google / TikTok / X / FB / IG） | 高清、私密、被风控的内容 | 只能拿到公开低清，或直接 403 |

## 三、安装：三步

### 第 1 步：装 DSH Desktop

官网装好后登录，能正常开一个会话即可。

### 第 2 步：加插件（三选一）

**方式 A：插件市场加索引源（推荐，能自动更新）**

1. 左侧「插件」→「发现」→「添加索引源」
2. 粘贴：`https://hbycwzm001.github.io/dsh-plugin-media-extract/market/index.json`
3. 列表里找到 **视频解析（media-extract）** → 安装

**方式 B：git 直装**（知道命令的话）

```bash
dsh plugin add git+https://github.com/hbycwzm001/dsh-plugin-media-extract.git#a93ffe4810465dc2a88a967161ac972cbcf1a676
```

**方式 C：离线 zip**
把仓库打包成目录，在「插件 → 从本地目录安装」里选它。

> 装完可能需要重启一次 DSH（插件在首次加载时会提示 `restart-required`），重启后顶部会出现「解析」标签。

### 第 3 步：第一次解析（引擎自动下载）

装完插件**不用手动装引擎**：第一次点「解析」时，插件会自动下载约 240MB 的引擎包并解压到：

```
C:\\Users\\<你>\.dsh\media-extract\extract-tool\
    extract.exe
    _internal\
    models\sense-voice-onnx\   ← 228MB 语音模型
    scripts\                   ← 小红书 / YouTube 辅助脚本
    config.json                ← 你的代理配置
    output\                    ← 兜底输出目录
```

下载慢或失败时，可以手动：

```
https://github.com/hbycwzm001/media-extract-tool/releases/latest/download/extract-tool-win64.zip
```

下载后解压到 `C:\Users\<你>\.dsh\media-extract\extract-tool\`（保证 `extract.exe` 在这一层）。

## 四、代理：IP、端口、账号、密码怎么来、往哪填

> 只有**海外平台**（YouTube / TikTok / X / Instagram / Facebook）需要代理；
> 抖音、小红书在国内直连即可，**不要**给它们套代理（会更慢且更容易风控）。

### 4.1 先搞清楚三种"代理"

| 类型 | 形式 | 浏览器能不能直接用 |
|---|---|---|
| **HTTP / HTTPS 代理** | `IP:端口` + 账号密码 | ✅ 能，**推荐** |
| **SOCKS5 代理** | `IP:端口` + 账号密码 | ⚠️ 浏览器**不支持** SOCKS5 账号密码认证 |
| **VLESS / Trojan 节点** | 客户端里的节点 | ❌ 浏览器不认，必须经客户端转成上面两种 |

这就是为什么"填了节点却打不开"——浏览器只认 HTTP/HTTPS/SOCKS5，而且只有 HTTP/HTTPS 能带账号密码。

### 4.2 现成的一套（我们已经搭好）

| 项 | 值 |
|---|---|
| 网关地址 | `proxy.jiouge.com` |
| 端口 | `8443` |
| 协议 | `HTTPS` |
| 账号 | `<你的账号>` |
| 密码 | `<你的密码>` |

这是部署在自己服务器（38.34.21.177）上的 **TLS 正向代理**，服务器上跑的是 `/root/tlsproxy.py`（systemd 服务 `dsh-tlsproxy`），
证书是 Let's Encrypt 正式证书（`proxy.jiouge.com`），所以浏览器不报证书错误、也不会被中间人重置。

### 4.3 想自己搭一套（给别的用户）

1. 一台海外 VPS（本例 38.34.21.177，Ubuntu 22.04）
2. 域名一条 A 记录指向它（本例 `proxy.jiouge.com`）
3. 签证书（80 端口被封时用 DNS-01，见 server 上的 `certbot` 记录）
4. 跑 TLS 正向代理，监听一个端口（本例 8443），Basic 认证
5. 得到四件套：`域名 / 端口 / 账号 / 密码`

### 4.4 填到哪里（两个地方，别搞混）

**① 引擎用（决定"能不能下载"）**

改 `C:\Users\<你>\.dsh\media-extract\extract-tool\config.json`：

```json
{
  "youtube_proxy": "https://<账号>:<密码>@<你的代理域名>:8443",
  "youtube_proxy_fallback": "http://127.0.0.1:7897"
}
```

或用工具改（推荐，不用碰文件）：

```
media_setup action=config patch={"youtube_proxy":"https://<账号>:<密码>@<你的代理域名>:8443"}
```

> 格式是 `协议://账号:密码@主机:端口`。不用代理就留空。
> 主代理连不上时，会自动尝试备用代理、本机探测到的代理（7897/10809/1080），最后直连。

**② 浏览器用（决定"网页能不能打开"）**

ego lite 里装「网关代理」扩展 → 点图标 → 填网关地址/端口/协议/账号/密码 → **保存并启用**。

```
网关地址：proxy.jiouge.com
端口    ：8443
协议    ：HTTPS
账号    ：<你的账号>
密码    ：<你的密码>
生效范围：全部站点走代理（推荐）
```

点完状态条显示「已启用：https://<你的账号>@<你的代理域名>:8443 · 全部站点走代理」就是成功的。

## 五、ego lite（浏览器）与登录态

### 5.1 为什么要它

小红书和抖音把内容藏在 JS 渲染 + 设备指纹后面，纯 HTTP 抓不到原图/原视频。
ego lite 是真实 Chromium，插件让它打开页面、从页面数据里取直链——**等同于你手动右键另存**。

### 5.2 装

1. 从 `https://lite.ego.app/` 下载安装
2. 首次启动会让用户点一次 onboarding（唯一必须人工的一步）
3. 装好扩展：`chrome://extensions` → 开发者模式 → 加载已解压的扩展 → 选 `ego-proxy-ext` 目录

### 5.3 登录态（影响成功率）

在 ego lite 里各登录一次，插件会自动导出 cookies 给引擎用：

| 平台 | 登录后效果 |
|---|---|
| Google（YouTube） | 不再报 "Sign in to confirm you're not a bot"，能出 1080p |
| TikTok | 无水印原片、私密视频 |
| X / Instagram / Facebook | 需要登录才能看的内容 |

导出是自动的（cookies 超过 12 小时会自动重新导出），你只要保证**在 ego 里是登录状态**。

## 六、日常使用

1. 顶部点「解析」
2. 把**整段分享文案**粘进去（不用手动挑链接，插件会自己抽）
3. 需要语音转写就保持「转写语音」勾选
4. 点「解析」→ 等 20~60 秒
5. 结果按顺序展开：**视频/图片 → 文案 → 标题 → 转写 → 本地文件**
6. 视频可直接播放；点「打开位置」跳到 `D:\工作台\<标题>\`；点「下载到…」另存
7. 文案/标题/转写右侧有「复制」；转写有错别字可点「✎ 纠错别字」

## 八、常见问题

| 现象 | 原因 | 怎么办 |
|---|---|---|
| `Sign in to confirm you're not a bot` | YouTube 判定出口 IP 是机房 | 换代理出口；在 ego 里登录 Google 后重试 |
| `HTTP 403 Forbidden` | CDN 拒绝该出口 IP 的下载 | 换出口（配 `youtube_proxy_fallback`），或等 30 分钟 |
| `小红书 - 你的生活兴趣社区` / 只有 logo | 笔记失效或未登录 | 换一条能正常打开的链接；在 ego 里登录小红书 |
| `笔记暂时无法浏览 (300031)` | 作者删除/设私密 | 无解，换一条 |
| 视频 0:00 播不了 | 引擎没抓到媒体，或文件被占用 | 重新解析一次；关闭占用该文件的播放器 |
| 下载 240MB 很慢 | 走的是 GitHub | 用 `media_setup action=download` 重试，或手动下载解压 |
| 代理填了还是不通 | 接口是 SOCKS5（浏览器不支持账号密码） | 改成 HTTP/HTTPS 类型；或让对方开 HTTP 入站 |
| 装了插件没看到「解析」 | 需要重启 DSH | 完全退出 DSH 后重新打开 |

## 十一、SOCKS5 与代理自动探测

引擎内置 `PySocks`，两种代理写法都支持：

| 类型 | 写法 |
|---|---|
| HTTP / HTTPS | `http://账号:密码@主机:端口` |
| SOCKS5（带认证） | `socks5://账号:密码@主机:端口` |

**不需要手填的情况**：本机开着 Clash / v2rayN 时，引擎会依次探测
`http://127.0.0.1:7897` → `http://127.0.0.1:10809` → `http://127.0.0.1:7890` → `http://127.0.0.1:1080` → `socks5://127.0.0.1:10808`，
命中哪个用哪个；一个都不通时还会退回直连重试一次。所以扫码导入节点的用户**什么都不用配**。

> 注意：机场客户端里的「节点」（vless / ss / trojan）浏览器和 yt-dlp 都不认识，必须由客户端（Clash / v2rayN）转成本机端口后再用。
