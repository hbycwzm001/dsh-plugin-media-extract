DSH Plugin · media-extract

视频解析插件 · 使用图谱

粘一条链接 → 20~60 秒 → 拿到无水印原片、文案、语音转写。支持抖音、小红书、TikTok、YouTube、Facebook、X（推特）、Instagram，全部在本机完成。

1它到底长在哪

装好插件后，DSH 对话窗口上方的标签栏会多出一个「解析」。

对话· 轨迹· 上下文· 队列→ 解析 ← 新增

点开就是你唯一要面对的界面：一个输入框 + 一个蓝色「解析」按钮 + 一个「转写语音」勾选。没有第二步配置，不用开命令行。

2五步操作

从粘链接到拿到文件，全程 5 个动作。

1

点顶部「解析」

对话区换成解析面板。

2

粘链接（整段分享文案也行）

「8.28 复制打开抖音，看看【…】 https://v.douyin.com/xxx/ …」这种整段文字可以直接丢进去，插件会自己把链接抠出来。

3

点「解析」

需要语音转文字就保持「转写语音」勾选；纯下载可以取消。

4

等 20~60 秒

面板显示「解析中…」和已用秒数。切到别的会话再切回来，进度还在，不会丢。

5

看结果，按顺序展开

视频（直接播放）→ 文案（可复制）→ 标题 → 转写（可纠错别字）→ 本地文件（打开位置 / 下载到…）。

3数据怎么流动

你的链接在本地跑完一整圈，不经过任何第三方服务器。

你粘的链接→ 解析面板→ 插件（DSH 内）→ extract.exe→ 本地文件
国内抖音 / 小红书

用本机 Chrome 真实渲染页面，从页面数据里捞原片原图直链。
需要：电脑装了 Google Chrome。

海外TikTok / YouTube / Facebook / X / IG

由 yt-dlp 下载，自动挑选可用出口（多出口重试）。
需要：本机能翻墙（Clash / v2rayN 开着即可）。

产物落盘：D:\\工作台\\<标题>\，每个作品一个文件夹，里面是 mp4/webp + 同名 .txt。

4依赖：谁必须装，谁内置

引擎包一次下好，之后不用再管 Python、Node、ffmpeg。

东西必须?说明
DSH Desktop ≥ 0.2.2-rc.1必须宿主应用
本插件 media-extract必须提供「解析」面板与工具
解析引擎 extract.exe（240MB）必须首次解析自动下载，含全部运行时
语音模型 SenseVoice-Small（228MB）随引擎已打包在引擎里，不需要单独下载
Python / Node / ffmpeg / quickjs随引擎全部内置，用户无需安装
Google Chrome国内平台需要抖音/小红书靠它渲染；Edge、360 不认
能翻墙的客户端（Clash / v2rayN）海外平台需要插件自动探测本机端口，不用手填
各平台登录态可选YouTube 高清、私密内容才需要
ego lite 浏览器可选只影响小红书成功率，不是必需

6海外平台的代理：三种情况

插件只在需要时才用代理，国内两个平台不走代理。

你的情况要不要配怎么做
电脑开着 Clash / v2rayN（扫码导入那种）不用配插件自动探测 7897 / 10809 / 7890 / 1080 / socks5:10808，挑一个能连的用
客户端在别的端口填一行config.json 里 youtube_proxy = http://127.0.0.1:端口
别人给你远程代理（IP+端口+账号密码）填一行http://账号:密码@主机:端口；SOCKS5 带认证也行：socks5://账号:密码@主机:端口
代理配置文件位置：C:\\Users\\<你>\.dsh\media-extract\extract-tool\config.json
也可以用工具改：media_setup action=config patch={"youtube_proxy":"..."}

7三种典型输入，三种输出

视频

抖音 / TikTok / YouTube…

输出：1 个 mp4 + 文案 + 转写

图文

小红书 / 抖音图文

输出：整套原图（小红书最高 2304×4096）+ 文案

纯文字

整段分享文案

自动从文字里抠出第一条链接，其余忽略

8给别人用：三句话

  1. 装「解析」插件 —— 首次解析会自动下载 240MB 引擎（含语音模型），等着就行。
  2. 平时怎么翻墙就怎么开着（Clash / v2rayN），插件自己找端口，不用填。
  3. 解析 YouTube 若提示要登录，在弹出窗口里登一次 Google，之后不用再登。
不需要装 ego lite，不需要装浏览器代理扩展 —— 这两样只在自己要在浏览器里人肉看外网时才用得上。

9常见问题速查

现象原因 / 处理
YouTube 提示 Sign in to confirm you're not a bot机场是机房 IP。在该平台的浏览器里登录一次 Google，或换住宅节点
HTTP 403 Forbidden该出口被 CDN 限流。换节点，或等 30 分钟；插件会自动换备用出口重试
小红书只出来一个红色 logo笔记已失效（作者删除/设私密）或未登录。换一条能正常打开的链接
视频进度条 0:00 播不了重新解析一次；文件名带表情符号时个别播放器会挑食
点「解析」没反应看面板是否显示「引擎下载中」；首次要等 240MB 下完
抖音提示未找到 Chrome装 Google Chrome（Edge/360 不认）

10一句话总结

装插件 → 粘链接 → 出原片和文字。
国内靠本机 Chrome，海外靠本机代理，两者都不需要额外配置就能被自动找到。
